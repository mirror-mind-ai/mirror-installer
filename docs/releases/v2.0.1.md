# Mirror Mind for Windows 2.0.1 — Fewer Questions

**Date:** DRAFT · **Installs:** mirror-mind DRAFT · Pi (latest) · Node 24 (latest) · Git 2.56.0.2

## Highlights

- **The core with every Windows fix so far.** The pin moves to the first
  `mirror-mind` release that carries
  [mirror#53](https://github.com/mirror-mind-ai/mirror/pull/53) (Claude Code's
  hooks and the plugin's MCP server run the package's own bin when npm's global
  entry is a shell shim, so a Windows npm install logs conversations and serves
  MCP) and [mirror#50](https://github.com/mirror-mind-ai/mirror/pull/50)
  (`runtime diagnose` no longer counts its own verdict as an error), on top of
  0.39.2's [mirror#49](https://github.com/mirror-mind-ai/mirror/pull/49).
- **No language question when Windows already answered it.** The wizard asked
  for a language on every run. It now asks only when Windows is in neither
  Portuguese nor English; the identity page still switches it.
- **"Português (Brasil)"** in the identity page's language selector, with its
  accent.

## Installing

**Recommended: one line in PowerShell**, with no SmartScreen warning:

```powershell
irm https://raw.githubusercontent.com/mirror-mind-ai/mirror-installer/main/get.ps1 | iex
```

Or download `MirrorMind-Setup-2.0.1.exe` from this release; it is not
code-signed yet, so on first downloads SmartScreen says "Windows protected your
PC": click **More info → Run anyway**.

## Updating

An installed Mirror does not need this installer: `/mm-update` in Pi (or
`mirror runtime update`) brings the core forward. This release matters to new
installs.
