# Mirror Mind for Windows 2.0.2 — Starting From 0.40.0

**Date:** 2026-11-07 · **Installs:** mirror-mind 0.40.0 · Pi (latest; 1.5.0 when tested) · Node 24 (latest; 24.22.2 when tested) · Git 2.56.0.2

## Highlights

- **The pin moves to 0.40.0**, the core's first stable release under
  [the release train](https://github.com/mirror-mind-ai/mirror/blob/stable/docs/releases/v0.40.0.md).
  Two things a new user has from the first session: a session's replies are
  written into its own conversation and only there (CR151; before, a transcript
  could fill an earlier open conversation and read out of order), and a Journey
  can be deleted with its records behind a verified backup (CR200). No schema
  change, no migration.
- Nothing else in the installer changes. An installed 2.0.0 or 2.0.1 does not
  need this release: `/mm-update` takes it to 0.40.0 by itself, and that path
  was run again today (below).

## Installing

**Recommended: one line in PowerShell**, with no SmartScreen warning:

```powershell
irm https://raw.githubusercontent.com/mirror-mind-ai/mirror-installer/main/get.ps1 | iex
```

Or download `MirrorMind-Setup-2.0.2.exe` from this release; it is not
code-signed yet, so on first downloads SmartScreen says "Windows protected your
PC": click **More info → Run anyway**.

Already have Mirror? You do not need this: ask it `/mm-update`.
